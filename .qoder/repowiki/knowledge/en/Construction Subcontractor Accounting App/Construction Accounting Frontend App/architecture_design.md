Single-page React app bootstrapped in `src/main.tsx` that mounts `<App />` inside `React.StrictMode`. `App.tsx` owns global page state (`currentPage`, `selectedProjectId`) and renders the selected page component inside a shared `Layout` shell (sidebar + top bar) via a switch-based router; there is no client-side routing library — navigation is driven by prop callbacks. Pages live one level deep under `src/pages/` (Dashboard, Jobs, JobDetail, TimeTracking, Billing, WIP, Payroll, Financials, Settings). Shared UI primitives are split into `components/layout` (app chrome) and `components/ui` (Radix-derived badge/button/card). Cross-cutting concerns are centralized: `types/index.ts` defines all domain models (Project, CostCode, Phase, TimeEntry, Invoice, Bill, etc.) and the `PageRoute` union used throughout; `data/mock.ts` supplies in-memory datasets consumed by pages; `lib/utils.ts` provides formatting helpers and the `cn` class-merging utility. Styling uses Tailwind CSS v4 with a custom design token palette (e.g. `bg-canvas`, `text-ink`, `border-line`) configured via `tailwind.config.js` (outside scope). The build pipeline is Vite with the React plugin and Tailwind v4 plugin; an `@` path alias maps to `src/` so imports use absolute module paths.
