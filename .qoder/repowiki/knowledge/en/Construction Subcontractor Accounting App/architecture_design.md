The workspace root holds two guiding documents — a BuildBooks Product Spec Sheet and a Reusable AI-App Technology & Design Stack Playbook — that define the product scope and shared UI/tech conventions. The `app/` subdirectory is the single child: a self-contained React + Vite project whose pages (Dashboard, Jobs, JobDetail, TimeTracking, Billing, WIP, Payroll, Financials, Settings) consume shared types from `src/types`, mock data from `src/data/mock.ts`, and reusable UI primitives under `src/components/ui`, all wrapped by a common Layout/Sidebar shell in `src/components/layout`. There is no backend or separate service; cross-page state and navigation are handled entirely within this frontend app.
